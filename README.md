# APP SENA 📱

## Descripción del proyecto

APP SENA es una aplicación móvil desarrollada como proyecto de aprendizaje utilizando **React Native y Expo**. Su estructura permite construir una interfaz interactiva y sencilla para visualizar un producto, consultar su precio y modificar la cantidad mediante controles de aumento y disminución.

El proyecto busca poner en práctica conceptos de desarrollo de aplicaciones móviles, componentes, manejo de estados y navegación.

## Tecnologías utilizadas

- **React Native:** para construir la interfaz de la aplicación.
- **Expo:** para facilitar el desarrollo y la ejecución de la aplicación.
- **TypeScript:** como lenguaje de programación.
- **Expo Router:** para gestionar la navegación mediante archivos.

## Instalación y ejecución

Para descargar y ejecutar el proyecto localmente, sigue estos pasos:

### 1. Clonar el repositorio

```bash
git clone https://github.com/7Paula18/App_Sena.git
```

### 2. Ingresar a la carpeta del proyecto

```bash
cd App-Sena
```

### 3. Instalar las dependencias

```bash
npm install
```

### 4. Iniciar la aplicación

```bash
npx expo start
```

Al iniciar el servidor de desarrollo, aparecerán diferentes opciones para visualizar la aplicación:

- **Expo Go:** permite probar la aplicación desde un dispositivo móvil.
- **Emulador de Android:** permite ejecutarla en un entorno virtual de Android.
- **Simulador de iOS:** permite probarla en un entorno de Apple.
- **Navegador web:** permite visualizar la versión web, si está configurada.

## Estructura del proyecto

El código principal de la aplicación se encuentra organizado dentro de la carpeta `src/app`.

Esta estructura utiliza Expo Router, que permite organizar las pantallas y establecer la navegación mediante archivos.

## Funcionalidades actuales

- Visualización del nombre de la aplicación.
- Presentación de un producto y su precio.
- Botón para aumentar la cantidad.
- Botón para disminuir la cantidad.
- Actualización de la cantidad en pantalla mediante el manejo de estados.

## Configuración adicional

El proyecto cuenta con algunos comandos que facilitan su desarrollo:

```bash
npm run lint
```

Permite ejecutar las herramientas de revisión del código.

```bash
npm run reset-project
```

Restablece la estructura inicial del proyecto de Expo y permite comenzar nuevamente con una estructura limpia.
